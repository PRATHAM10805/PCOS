# Dataset

The dataset used by OvaTwin was obtained from IEEE DataPort.

Dataset:
PCOS data

Source:
IEEE DataPort

DOI:
10.21227/k3d8-tt94

The dataset is not included in this repository.

To run the project:

1. Obtain the dataset from the original source.
2. Place the CSV in this directory.
3. Rename it to:

dataset.csv
